# Worker safety — Australian client demonstration

See [OPERATING-GUIDE.md](OPERATING-GUIDE.md) for the current complete guide. The legacy filename is retained for existing links.

The primary navigation is Home, Worker safety, Evidence & report. Worker safety has four core areas. Queue warnings, Work-zone planning and Fleet & charging are supporting tools entered from related safety areas. Public works notices is inside Work-zone planning.

Worker safety keeps its independent state, geometry-based moving-object alerts, watch controls, worker roster, support workflow and offline snapshot simulation. The supporting model applies only to the Cremorne illustrative example. It never modifies a safety layout, sends a queue notification to a watch or establishes physical delivery.

Official road context is collapsed by default in Site layout. See [R1-DATA-SOURCES.md](R1-DATA-SOURCES.md) for source provenance.

Verification: 46 tests across model, safety, real-data-and-alerts, worker-support and workspace test files. Browser checks cover guided navigation, watch alerts, SOS and completion, context-preserving tool return, unmodelled sites, relocated notices and evidence exports.
